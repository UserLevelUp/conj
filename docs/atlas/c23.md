# C23 · How many legal orders?

**Random partial orders · Unresolved**

Is there a deterministic second-order entropy constant for random planar orders?

![A toy planar point order and its exact number of compatible total orders.](../../assets/c23.png)

*Figure provenance: A toy planar point order and its exact number of compatible total orders.* [Vector version](../../assets/c23.svg).

The number of linear extensions is the number of compatible total orderings. The proposal concerns its logarithm on the order-n scale.
